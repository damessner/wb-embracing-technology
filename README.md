# wb-embracing-technology

Statische Projektwebsite für **„Embracing Technology“** (Deutsch), geeignet für **GitHub Pages**.

## Seitenstruktur

- `index.html` – Startseite / Überblick
- `ziele.html` – Projektziele / Zielerreichung (inkl. interaktive Fortschrittsanzeige)
- `termine.html` – Termine / Meilensteine (inkl. interaktive Timeline)
- `inhalte.html` – Inhalte / Themenschwerpunkte (inkl. Filter und Akkordeon)
- `reflexion.html` – Reflexion / kritische Einordnung
- `assets/styles.css` – gemeinsames Design (responsive)
- `assets/script.js` – Interaktionen (ohne Framework)

## GitHub Pages aktivieren

1. Repository auf GitHub öffnen.
2. **Settings → Pages** öffnen.
3. Bei **Build and deployment** unter **Source** `Deploy from a branch` wählen.
4. Branch `main` (oder den Standardbranch) und Ordner `/ (root)` auswählen.
5. Speichern – die Seite ist nach kurzer Zeit unter der Pages-URL verfügbar.

## Lokal testen

Die Seite ist vollständig statisch. Zum lokalen Testen einfach `index.html` im Browser öffnen.
